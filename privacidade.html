Política de Privacidade

Atualizada em 28 de outubro de 2026.

Esta política vale para o aplicativo Nação GTA, usado apenas pelo dono do canal Nação GTA para publicar vídeos e imagens nos perfis do próprio canal no YouTube, no Instagram e no Facebook.

O que o aplicativo acessa

O aplicativo usa os Serviços de API do YouTube e a API da Meta somente com as contas do próprio canal, para enviar vídeos, publicar posts e ler estatísticas desses perfis. Ele não acessa contas de outras pessoas e não coleta, vende nem compartilha dados de usuários.

Onde os dados ficam

As chaves de acesso ficam guardadas só no computador do dono do canal. Nenhum dado pessoal de terceiros é armazenado.

Serviços do Google e do YouTube

Ao usar este aplicativo, valem também os Termos de Serviço do YouTube e a Política de Privacidade do Google. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Como apagar os dados

O único dado guardado é o token de acesso da conta do próprio dono do canal. Para apagar, basta revogar o acesso do aplicativo "Nação GTA" em myaccount.google.com/permissions (o token deixa de funcionar na hora) e excluir o arquivo do token do computador. Nenhum dado obtido pela API do YouTube é mantido por mais de 30 dias.
