Nação GTA · internal publishing tool

This is a private, single-user command-line tool. It is used only by the owner of the YouTube channel NAÇÃO GTA (Brazilian fan channel about Grand Theft Auto VI) to upload the channel's own original Shorts. It has no public users, no web interface and no sign-up.

What it does

  1. The owner produces an original Short (own narration, captions and editing) on his computer.
  2. The Short is placed in a local publishing queue with its title, description and tags.
  3. At the scheduled time, the tool calls videos.insert to upload the file to the owner's own channel, with containsSyntheticMedia declared when applicable.
  4. It calls channels.list (mine=true) to confirm which channel is connected and read its public statistics.

API usage

  • Scopes: youtube.upload and youtube.readonly.
  • Volume: about 2 to 3 uploads per day (up to 3 Shorts per day during launch week).
  • Only the owner's own Google account is authorized. No data from other YouTube users is accessed, stored or shared.
  • OAuth tokens are stored only on the owner's computer.
